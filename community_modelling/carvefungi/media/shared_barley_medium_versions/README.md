## Important distinction

There are two layers:

1. **Model exchange reactions**: reactions present in a fungal model, for
   example `UF03044_E` for guaiacol in the Fusarium CarveFungi model.
2. **Simulation medium rows**: the uptake rows given to MICOM, for example
   `EX_guaiacol_m`.

The model can contain many exchange reactions, but only the reactions listed in
the medium file are opened as external nutrients for that simulation. Bacterial
cross-feeding can still occur through compatible community exchange routes.

## Interpretation

The strict shared medium supports Bipolaris CarveFungi growth after its shared
interface additions, but Fusarium CarveFungi with the same 52-component biomass
does not grow on that strict medium. Fusarium growth is restored by adding a
compact selected supplement from its native CarveFungi medium:

- amino-acid-related exchanges
- lipid/fatty-acid/sterol exchanges
- vitamin/cofactor exchanges
- guaiacol

This expanded medium should be treated as a **Fusarium-compatible shared medium
variant**, not as a replacement for the original Bipolaris comparison medium.
